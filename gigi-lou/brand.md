# GIGI LOU — Brand Aesthetic

## Mood
Rich, luxe, quiet luxury. Calm, confident, never loud.

## Palette
| Color | Hex |
|-------|-----|
| Ivory | `#F7F2EA` |
| Champagne | `#E8D9C0` |
| Soft gold | `#C2A26B` |
| Mocha | `#6B4F3A` |
| Noir | `#141414` |

## Type
- Headlines: elegant serif (Playfair Display, Cormorant Garamond, Bodoni)
- Body: clean thin sans (Montserrat Light, Lato Light)
- Wordmark: `GIGI LOU` in spaced capitals

## Voice
- Short sentences. Few words. Let it breathe.
- Words to use: curated, timeless, refined, signature, effortless, elevated
- Avoid: "cheap", "sale!!!", heavy emoji, all-caps shouting
